# UAV 下载接入

P20 0.4.3 直接调用固定版本 UAV（3.1.4，提交见 vendor/uav/upstream.lock.json）。输入受支持的 Jable/MissAV/SupJav HTTPS 详情页后自动路由到 UAV。纯番号依次尝试 MissAV、Jable；SupJav 的数字详情页需要直接提供链接，不进行番号搜索。显式指定其他下载器的行为保持原样。

每个任务在自己的 source-N 目录启动子进程；下载器只负责解析、分片、合并。默认选择最高画质、每片最多四个线程。进度通过回调输出为内部事件，下载过程消息显示在任务详情中。分片结束时最多显示 99%，合并完成并通过 ffprobe 视频轨道和时长检查后显示 100%。主进程非零退出、取消或没有成品都不会进入上传。

取消沿用 P20 的标志及进程组终止；容器停止时子进程随容器结束，重启后沿用中断任务恢复策略。无需单独的宿主机服务、监听端口、API 密钥或共享浏览器 profile。UAV 的状态目录限制在任务目录中。P20 继续负责 SHA-256、桌面加密打包、手机文件交付、QQ Flash 上传、确认取回与清理。

原始视频仅通过同目录重命名交回 P20，不为命名复制视频。只上传校验过的 MP4，不上传分片、封面或内部状态。现有 auth_ref 的请求头用于媒体请求；此实现不自动导入浏览器 Cookie，也不保证验证页能够自动通过。SupJav 在东京 VPS 上仍可能被验证页阻挡，任务会明确失败。

安装与运行由标准 Dockerfile 完成；源码和许可证随仓库保存，无启动时 git 拉取或静默升级。维护时应同时更新提交锁、原始源码、许可证和依赖并重新验收。

运维验收可用 P20_UAV_RESOLUTION=lowest 降低测试视频体积；生产默认 highest。手工启动源码环境时，P20_UAV_SOURCE 必须指向固定源码的 src 目录，并安装 vendor/uav/requirements.txt。
